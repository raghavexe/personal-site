# raghav-tengse.vercel.app

My personal website — built with React Router, TypeScript, and Tailwind CSS.

🔗 **Live:** [here](https://raghav-tengse.vercel.app)

## Getting Started

```bash
npm install
npm run dev
```

App runs at `http://localhost:5173`.

## Build

```bash
npm run build
```
